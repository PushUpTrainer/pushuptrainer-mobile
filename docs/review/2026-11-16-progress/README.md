# Исправления статистики после ревью

Добавлены серия тренировок, общее число тренировок и среднее число повторений. Все четыре общих показателя расположены сеткой 2x2. Для пустого дня показывается сообщение, для полностью пустой истории - предложение начать тренировку с переходом в подготовку. Нулевые сессии не участвуют в расчётах. Константы ViewModel остаются в private companion object в конце класса.

Сверка с Figma: [заполненный экран](https://www.figma.com/design/2rUtNM1WTKXJ8oCyqUMO7x/?node-id=332-3752), [пустой день](https://www.figma.com/design/2rUtNM1WTKXJ8oCyqUMO7x/?node-id=280-1990), [пустая история](https://www.figma.com/design/2rUtNM1WTKXJ8oCyqUMO7x/?node-id=323-3254). Использованы проектные скиллы UI, ViewModel, DI и навигации.

| Подтверждённая проверка | Результат |
| --- | --- |
| Android: `:shared:testAndroidHostTest`, `:androidApp:assembleDebug` | 49 тестов без ошибок, APK собран |
| iOS: `:shared:iosSimulatorArm64Test`, сборка Xcode | 53 теста без ошибок, приложение собрано |
| Расчёты и состояние | Проверены серия через границу года и часовые пояса, пропуск дня, исключение нулевых сессий, округление среднего, обновление и очистка истории |
| Навигация | Тест проверяет переход в подготовку, повторное нажатие без дубля и возврат к существующему экрану |
| iOS 27.2, iPhone 17e | Через интерфейс проверены светлая/тёмная темы, пустая история, переход в подготовку, завершение с нулём без добавления истории, выбор дня, предыдущий месяц и возврат на сегодня |
| iOS с контрольной историей | Интерфейс и дерево доступности: 86 повторений, 6 тренировок, рекорд 16, среднее 14,3 и серия 4 дня. После переноса сегодняшней контрольной записи на вчера - пустой сегодняшний день и серия 3 дня, общие значения прежние |
| Android, Medium Phone API 37 | Приложение установлено и запущено через Android Studio |

Проверки платформ выполнялись последовательно. Контрольные записи создавались только в базе симулятора iOS и удалены после проверки; исходные две нулевые записи сохранены. Проверена статистика на известных данных.

Значения рекорда и среднего дополнительно зафиксированы в дереве доступности iOS.
